API Reference

Authentication

Include your API key in every request using one of these headers:

X-API-Key: cliplens_your_key_here # or Authorization: Bearer cliplens_your_key_here

Base URL

{{ request.scheme }}://{{ request.get_host }}/api/v1/

Endpoints

MethodPathRequired permissionDescription
GET /api/v1/search/?q=query search:global / search:channel / search:playlist Search videos. Optional: limit, offset.
GET /api/v1/videos/{id}/ video:read Video metadata, HLS URL, AI summary.
GET /api/v1/videos/{id}/transcript/ video:read Full transcript. Add ?format=vtt for VTT file.
GET /api/v1/videos/{id}/chapters/ video:read Named chapters with timestamps.
POST /api/v1/videos/upload/ video:upload (scoped) Upload a video. Multipart: file, title. channel_id optional if key is scoped to one channel.

Example: Search

curl -s "{{ request.scheme }}://{{ request.get_host }}/api/v1/search/?q=safety+briefing&limit=5" \ -H "X-API-Key: cliplens_your_key_here"

Example: Get Video

curl -s "{{ request.scheme }}://{{ request.get_host }}/api/v1/videos/<uuid>/" \ -H "X-API-Key: cliplens_your_key_here"
