Fill Missing Scene Descriptions

          
Finds videos with no BLIP/Florence-2 captions and re-queues full frame analysis. Use after model install or if initial analysis was interrupted.

            CLIP · also re-runs
          

        

      

      

        

          
          
        

        

          
          
        

        
      

      

        
      

      

    


    
    
🔬 Individual AI Steps


    
    

      

        
📦

        

          
Run YOLO Object Detection

          
Re-runs YOLOv8 on existing videos and updates VideoFrame.labels only. Does not touch BLIP, CLIP, or face data. Useful after switching YOLO model versions.

          

            YOLOv8n · Object Labels
          

        

      

      

        

          
          
        

        

          
          
        

        

          
          
        

        
      

      

        
      

      

    


    
    

      

        
🖼️

        

          
Run BLIP / Florence-2 Scene Captions

          
Re-runs scene captioning on frames and updates VideoFrame.description. By default only fills frames with an empty description. Use Force to overwrite existing captions.

          

            BLIP / Florence-2 · Scene Caption
          

        

      

      

        

          
          
        

        

          
          
        

        

          
          
        

        

          
          
        

        
        
      

      

        
      

      

    


    
    

      

        
🔍

        

          
Run CLIP Embeddings

          
Re-computes CLIP visual embeddings on frames and updates VideoFrame.clip_embedding. Needed for semantic/visual search. By default only fills missing embeddings.

          

            CLIP · Visual Embedding
          

        

      

      

        

          
          
        

        

          
          
        

        

          
          
        

        
        
      

      

        
      

      

    


    
    

      

        
👤

        

          
Run InsightFace Detection

          
Re-runs face detection + ArcFace embedding on frames. Replaces existing DetectedFace rows for each processed video and re-clusters into FaceIdentity groups. Does not touch YOLO, BLIP, or CLIP.

          

            InsightFace buffalo_l · Faces
          

        

      

      

        

          
          
        

        

          
          
        

        

          
          
        

        
      

      

        
        ⚠️ Replaces all face data for processed videos.

📥

        

          
Ingest Videos from Filesystem

          
Scans media/originals/ for video files not yet in the database, creates Video records, and kicks off HLS encoding + full AI analysis. Use for batch server-side imports (no browser upload needed).

          

            FFmpeg · HLS Encoding
            Full AI pipeline triggered
          

        

      

      

        

          
          
        

        

          
          
        

        

          
          
        

        
        
      

      

        
      

      

    


    
    

      

        
🔧

        

          
Patch HLS Master Playlists

          
Rewrites master.m3u8 to include the RESOLUTION tag on each quality variant. Fixes hls.js level selector. No re-encoding — file edits only.

          

            HLS · File edit only
          

        

      

      

        

          
          
        

      

      

        
      

      

    


    
    

      

        
🎞️

        

          
Generate Seek-bar Sprite Sheets

          
Extracts one frame every 5 s and stitches them into a single JPEG sprite sheet per video. Powers the hover-preview on video thumbnails. New videos get sprites automatically; run this to backfill older uploads.

          

            FFmpeg · Frame Extraction
          

        

      

      

        

          
          
        

        

          
          
        

        

          
          
        

        
        
      

      

        
        Queues FFmpeg jobs to Celery — worker must be running.

Generate / Regenerate Captions

          
Transcribe speech to SRT subtitles. Runs on videos missing auto-generated captions, or all videos with --force. Queues to the captions Celery queue.

          

            faster-whisper · Speech-to-Text
          

        

      

      

        

          
          
        

        

          
          
        

        

          
          
        

        

          
          
        

        

          
          
          ISO 639-1 code (en, hi, fr, de, …)
        

        
        
      

      

        
      

      

    

    

    
    

      

        
🎙️

        

          
Speaker Diarization

          
Who spoke when? Segments transcripts into per-speaker time ranges. Requires whisper captions to be run first. Requires HF_TOKEN + model acceptance.

          

            pyannote/speaker-diarization-3.1 · Voice Segmentation
          

        

      

      

        

          
          
        

        
        
      

      

        
        Captions must exist first.
      

      

    


    
    
👤 Faces, speakers & identity


    
    

      

        
🔗

        

          
Rebuild Speaker ↔ Face Suggestions

          
Recomputes who-appears-when-they-speak suggestions by cross-referencing diarization time ranges with face detection timestamps. No pyannote re-run — uses existing DB data only. Use after importing new faces or tuning overlap heuristics.

          

            DB-only · No inference
          

        

      

      

        

          
          
        

        

          
          
        

        

          
          
        

        
      

      

        
        Large libraries may take a while — use channel, video, or limit to scope.
      

      

    


    
    

      

        
🧑‍🤝‍🧑

        

          
Propagate Identities

          
After you name a person on the /faces/ page, run this to find all other "Person #N" auto-detected faces that are actually the same person and merge them. Uses ArcFace cosine similarity.

          

            ArcFace · Embedding Comparison
          

        

      

      

        

          
          

            
            0.45
          

          Higher = stricter matching (fewer merges).
        

        
      

      

        
      

      

    


    
    

      

        
✅

        

          
Auto-confirm High-confidence Faces

          
Bulk-confirms unreviewed face crops whose ArcFace embedding is very close to their identity's reference. Saves review time when faces are clearly correct. Always dry-run first.

          

            ArcFace · Cosine Similarity
          

        

      

      

        

          
          

            
            0.75
          

          0.75 = safe default. Lower values confirm more but risk false positives.
        

        

          
          
        

        

          
          
        

        
      

      

        
      

      

    


    
    

      

        
🏷️

        

          
Rename Auto-detected Identities

          
One-time migration: renames legacy "Person 1", "Person 2" style names to globally unique "Person #<id>" format. Run once after migrating from an older version.

          

            DB-only · One-time migration
          

        

      

      

        
      

      

        
      

      

    


    
    
📸 Photos & Location


    
    

      

        
🌍

        

          
Backfill Photo GPS Coordinates

          
Reads GPSInfo from stored EXIF data for photos that have GPS in their EXIF JSON but no latitude/longitude in the DB. Populates the indexed geo fields and re-runs Named Place assignment. Run this once after upgrading to the Named Places feature.

          

            DB-only · No inference
          

        

      

      

        
        
      

      

        
        Safe to run multiple times — skips photos that already have lat/lng.
